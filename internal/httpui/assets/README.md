# Rubik

Variable upright font, weights 300–900, bundled locally to avoid third-party
requests. Supported glyphs use Rubik; other scripts use system fallback fonts.
Source: Google Fonts, `ofl/rubik/Rubik[wght].ttf`, revision
`8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5`.

[Upstream font](https://github.com/google/fonts/blob/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/rubik/Rubik%5Bwght%5D.ttf).
License: [SIL Open Font License 1.1](OFL-Rubik.txt), retained unmodified.
SHA-256: `1b3a7437ba2af80e465e773ed60c5036d1ba6ace492d89046dbcf18fb31e4e88`.

The HTTP URL `/assets/rubik-v1.ttf` is versioned. Bump its version when changing
the font bytes. Do not add remote font imports to the template.
