# Дизайн Словника

## Напрям

Власник 2026-11-09 надав три джерела: локальний brief Town, особистий
брендбук і зразок кремового фону. Реалізація поєднує їх у пошуковий
інструмент; остаточне приймання вигляду залишається за власником.

- **Town:** великі заголовки, багато простору, стримані рамки та невеликі
  радіуси. Маркетингові тексти, графіка й анімація Town не переносяться.
- **Брендбук:** Rubik 400, зелений `#168A53`, жовтий `#FED74F`, чорний.
  За запитом власника знак із `Original Logo2.svg` розміщено поруч із назвою
  Slovnyk: жовта монограма на зеленому тлі, зі збереженням пропорцій.
- **Зразок:** фон `#FDF6E3`, визначений за центральним пікселем зображення.
  Трохи світліша панель `#FFFBF0` відділяє форму без білого тла.

## Правила реалізації

Кнопки й посилання використовують темніший зелений `#116B41` для читабельності.
Жовтий — акцент знака, виділення тексту та обрамлення фокуса. Результати
розділені лініями, без окремої важкої картки для кожного слова.
На вузькому екрані поля й кнопка стають в одну колонку; DOM-порядок форми:
запит → вихідна мова → цільова мова → відправлення. Збережено native selects,
видимі labels, skip link, `lang`/`dir`, статуси та роботу без JavaScript.
Не додано нових UI-фраз; всі 31 каталоги залишаються `ai-draft`.

Rubik вбудовано в Go binary та віддається через `/assets/rubik-v1.ttf`.
Дозвіл CSP `font-src 'self'` однаковий для пошуку й сторінок слів;
зовнішніх шрифтів, аналітики чи скриптів немає. Для інших писемностей
працює системний fallback. [Походження та ліцензія шрифту](../internal/httpui/assets/README.md).
